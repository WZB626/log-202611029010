首页学习路线

  

    ROADMAP
    
6 周自学路线

    
路线说明
      
    
        
  • 前 5 周对应本站 12 章内容
    • 
        
  • 每周 5–7 小时即可跟上
    • 
        
  • 编程只看不练等于没学，请务必动手敲代码
    • 
      

    

  

  

    

      
第 1 周

      

      
入门热身
搞懂“程序是什么、怎么运行”，装好编译环境（推荐 Dev-C++ 或 VS Code），写出并运行第一个 Hello World。
第 1–2 章环境搭建

    

    

      
第 2 周

      

      
语法地基
吃透变量与数据类型、运算符、输入输出。多写几个“读入两个数做运算”的小程序巩固格式符。
第 3–5 章多敲多练

    

    

      
第 3 周

      

      
流程控制
分支与循环是本学期最重要的两种结构。每道题先画流程图再写代码，重点练循环边界与嵌套。
第 6–7 章画流程图

    

    

      
第 4 周

      

      
数组与函数
用数组存批量数据、用函数拆分问题。理解参数传递与作用域，尝试自己写一个递归函数。
第 8–9 章模块化

    

    

      
第 5 周

      

      
算法起步
掌握排序与查找的经典写法，建立“时间复杂度”直觉。开始每天在评测平台刷 1–2 道简单题。
第 10–11 章刷题

    

    

      
第 6 周起

      

      
持续进阶
学习指针、结构体、链表与文件操作；每两周做一个综合小项目（学生成绩管理、猜数字游戏等）。
指针结构体项目驱动

    

    

      
贯穿始终

      

      
养成好习惯
变量命名有意义、写注释、保持代码缩进；遇到 bug 先读错误信息，再用调试器或 printf 定位。
代码规范调试

    

  

  

    推荐资源
    
视频课：浙江大学翁恺《C 语言程序设计》公开课；教材：《C Primer Plus》（中文版）；练习平台：PTA（拼题A）、洛谷、力扣（先做简单题）。这些资源公开免费，与本站内容配合使用效果最好。

    常见错误对照
    
错误写法类型修正 / 原因

    
      
int a = 5 忘记分号编译错误每条语句以 ; 结尾

      
scanf("%d", a)运行异常变量前要加 &：scanf("%d", &a)

      
if (a = 1)逻辑错误比较用 ==；= 是赋值

      
5 / 2结果不对整数除法结果是 2；想得 2.5 需写 5.0 / 2

      
a[10] 访问第 11 个运行崩溃数组下标从 0 开始，越界非常危险

      
忘记 return 0;警告/不良习惯main 函数末尾写 return 0;
